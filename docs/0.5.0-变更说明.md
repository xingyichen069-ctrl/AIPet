# 0.5.0 变更说明

## 记忆与 prompt 注入

`src/memory.py` 现在按 journal 和排除记忆数据库的文件状态缓存读取结果，同一条记忆的分词结果和时间戳也会复用。高记忆量检索先计算分数，再用固定大小的候选堆取前段，避免每轮对全部条目做完整排序；候选池保留了 token 预算和近期兜底需要的余量。

原有评分公式、说话人权重、时间衰减、标签加成、隐私过滤和近期记忆兜底保持不变，优化重点是重复计算和排序成本。

## 主题图标

主题仍由 `themes/appearance.json` 和本地外观设置控制，新增 `satori` 与 `flandre` 两套配色和矢量图标：

- 古明地觉使用红色觉之瞳，思考期间短暂闭眼，完成后固定恢复睁眼。
- 芙兰朵露使用七色菱形组成的彩色翅膀，思考时轻微左右抖动。
- 古明地恋保留心形装饰，思考时做轻微跳动，不连续旋转。

图形由 PySide6 的 `QPainter` 绘制，刷新由已有 `QTimer` 控制，不增加第三方动画库；空闲时停止刷新。主题只改变界面装饰，不替换 Live2D 模型。

## 对话排版

气泡最大宽度随滚动区域变化，放大窗口时会同步调整已有消息的宽度和点数字号。字体采用点数设置，减少 Windows 下固定像素字号造成的模糊和比例失衡。
