# QQ 定时任务

每日符卡默认对所有群关闭。主人在需要的群里开启后，每天北京时间 **10:00、14:00、22:00** 各发一张；三个时段合计三张。各群的开关与轮换进度独立，保存后重启仍保留。

## 在群里使用

发送时实际 @机器人，再输入指令：

| 指令 | 用途 |
|---|---|
| `/符卡 开启` | 从下一个时段开始在本群推送 |
| `/符卡 关闭` | 关闭本群推送；已提交给 QQ 的消息无法由开关撤回 |
| `/符卡 状态` | 查看开关、发送时间、最近结果和 QQ 错误码 |
| `/符卡 预览` | 查看下一张的排版，不推进轮换进度 |
| `/定时任务 列表` | 查看已安装的模板 |
| `/定时任务 开启 spellcards` | 按模板名称开启，关闭、状态和预览同理 |

只有已经绑定的主人可管理。指令只影响当前群，不接受在私聊中指定别的群。普通群消息即使写了这些文字，也不会触发开关。

## 发送样式与文档

开头固定为“叮！今日份符卡推送：”；下面是逐字竖排的符卡名，最后标注持有者。引号和短横线发送时转为竖排字符，文档中的原名保留。例如：

```text
叮！今日份符卡推送：
灵
符
﹁
梦
想
封
印
﹂
持有者：博丽灵梦
```

初始准备了 **128 张、81 位持有者、15 部作品**，每作 8–9 张，其中正作 104 张、小数点作 24 张；已收录《绀珠传》《天空璋》《鬼形兽》《锦上京》各 8 张。同一角色可有多张，各群按文档顺序循环；保留旧库开头 12 张，其余按作品交错编排。每天三次正常推送时，约 43 天轮换一遍。名称和出处见[符卡库](../templates/qq_tasks/spellcards.md#出处索引)；《东方求闻史纪》另作人物及符卡规则参考。推送只读取文档，不消耗模型或 Tavily 额度。

- 随代码保存的模板：`templates/qq_tasks/spellcards.json`、`templates/qq_tasks/spellcards.md`。
- 首次启动复制到本安装可编辑目录：`data/qq_tasks/`。之后代码更新不会覆盖这份副本。
- 开关、轮换位置和最近发送结果：`data/qq_schedules.json`。不要手动删除它来重置进度，否则会丢失去重记录。

本机可编辑文件位于项目目录的 `data/qq_tasks/`。修改其中的 Markdown 表格即可增加符卡；“解说”列为兼容通用模板而保留，每行统一填 `叮！今日份符卡推送`，冒号由程序添加。代码中的模板与实际运行副本分别保存，手工更新卡库时请先备份运行副本，不要覆盖 `qq_schedules.json`。修改 JSON 中的 `times` 可调整时段，格式为 `HH:MM`，统一按北京时间。下次检查即读取，无需重启；开关启用前也会校验内容。

## 扩展模板

复制 `spellcards.json` 和对应 Markdown 到 `data/qq_tasks/`，改成新的文件名，例如 `poems.json`、`poems.md`。JSON 中同步修改 `id`、`title`、`catalog` 与 `times`，然后用 `/定时任务 列表` 查看，再在目标群开启。

目前模板只声明每日时间与纯文本卡片，不执行脚本、命令或文档中的指令。卡片仍使用“符卡、持有者、解说”三列及竖排样式；其他模板如需两行开头，可在“解说”列用 `<br>` 分隔。要增加不同排版或新的任务类型，可在 `src/qq_schedule.py` 增加明确的类型和渲染器。模板最多 8 个，每个最多 6 个时段；卡片文档最多 300 条、128 KiB，最多管理 32 个群。

## QQ 权限和发送边界

使用官方主动消息接口，不需要当时有人 @机器人。QQ 客户端的主动消息开关、群禁言、机器人权限和平台限频仍然有效；允许接收全部群消息不等于允许主动发送。

接口返回无权限、已非群成员或被禁言时，会暂停该群对应任务；处理好权限后重新执行开启指令。其他失败记下结果，不在同一时段反复重试。“QQ 已受理”表示接口成功，不是群成员已读回执。

发送前先持久化本次时段。网络超时、退出或断电导致结果不明时不重发，避免重复刷群。仅执行当前两分钟内的有效时段，停机错过更早的时段不补发；启用时已经过去的时段也不补发。检查间隔约十秒，多群发送会依次排队，不能保证精确到秒。

状态文件损坏时停止发送并保留原文件；每个群任务只保留最近 8 条结果及轮换进度。定时发送复用现有 QQ 进程，关闭进程时一并停止，不会另开一个 QQ 网关。

官方说明：[消息收发概述](https://bot.q.qq.com/wiki/develop/api-v2/server-inter/message/overview.html)、[发送群聊消息](https://bot.q.qq.com/wiki/develop/api-v2/autogen/api/v2_groups_group_openid_messages.post.html)。
