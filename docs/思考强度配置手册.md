# 思考强度配置手册

新装默认 **max（极限）**。共六个手动档位，另有自动模式；切换档位不会改写人格。初次配置请先完成 [README](../README.md)，不用先理解整份参数表。

## 打开与切换

通过桌宠右键菜单打开思考面板，也可从对话窗口的菜单进入。选择日常、极限或自动等选项，当前选择保存在本机 `data/thinking.json`。保存配置后会重载；尚未绑定 Ctrl+Shift+T 等全局快捷键。

`data/thinking.example.json` 是发行模板，准备时只在用户文件不存在时复制。更新迁移保留旧档位及模型，不把新模板强行写入用户配置。

## 当前发行预设

| 档位 | 记忆配置预算 / 条数 | 输出 max_tokens | 推理配置 | 搜索提示 | 自检提示 |
|---|---|---|---|---|---|
| 省电 `frugal` | 3500 / 3 | 3000 | none | off | 无 |
| 日常 `daily` | 12000 / 12 | 8000 | none | on_demand | 无 |
| 认真 `serious` | 25000 / 25 | 20000 | medium | on_demand | 无 |
| 深究 `deep` | 50000 / 50 | 40000 | high | eager | 有 |
| 极限 `max` | 90000 / 80 | 80000 | max | always | 有 |
| 雷霆大思考 `thunder` | 120000 / 120 | 120000 | max | always | 有 |

表中的记忆预算约束程序估算的相关回忆块，包含日期、来源、说话人和截取标记；不是整个请求或服务商精确token上限，也不是费用或延迟保证。人格、真实聊天历史、工具结果和知识库各有自己的上下文。过长记忆会截取并标注“记忆片段已截取，原记录未改动”；阶段事实和近期兜底也受同一预算及条数限制。供应商可能限制最大输出，达到限制时会截断或拒绝请求。

省电与日常关闭思考。日常使用 temperature=1.25、frequency_penalty=0.4，并只开放 `get_time`、`recall`、`remember`、`mood`、`web_search`、`agreement`、`quiet_company`；需要文件/视觉/系统工具时选其他提供该工具的档位。

## 自动模式

`current` 改为 `auto` 或在面板选择“自动”，才会按问题分类。原代码按长度、疑问词、深度词、简单词和代码信号累计分数，阈值在 `auto_rules`：

| 分数 | 选择 |
|---|---|
| <8 | frugal |
| 8–<25 | daily |
| 25–<50 | serious |
| 50–<75 | deep |
| ≥75 | max |

thunder需要手动选择；自动规则不会选到它。包含词语只是启发式，不保证准确理解问题难度。

## 参数的实际含义

- `model`：填写当前API服务实际提供的模型名。`deepseek::`等前缀会在发送前剥离，不会据此切换供应商。非DeepSeek服务仍可能拒绝当前专用参数，见README的限制说明。
- `reasoning_effort`：当前配置映射识别 none/low/medium/high/max。none关闭思考；low保留low，medium与high映射为high，max映射为max。不是五种独立的服务端推理能力；不支持任意填minimal/xhigh/ultra。
- `max_tokens`：发给API的输出额度配置，范围是否接受由服务商和模型决定。
- `temperature`：当前适配只在关闭思考时发送；日常为1.25。更高不等于质量一定更好。
- `memory_budget`、`memory_entries`、`memory_floor`：控制回忆块的估算预算、条数和近期兜底。自动注入与本轮recall工具使用已确定的检索参数快照，中途切档不改变正在执行的一轮，也不修改全局配置。近期条目只在剩余预算和名额内补入。
- `search`：off会移除搜索工具；on_demand/eager/always主要改变给模型的提示，不等于代码强制每次联网。
- `self_check`：增加“回答前回头检查”的提示，没有独立第二次验证调用，不能称为双倍推理或质量保证。
- `verbosity`：控制建议篇幅的提示，角色仍读取当前人格。

费用取决于实际输入、输出、缓存、工具调用和服务商计费。没有可靠的固定“极限贵10–15倍”或“只多1–3秒”的保证。

## 修改配置

先备份自己的 `thinking.json`，然后只改对应字段。默认模型保留在各档 `params.model`。`secrets.json` 的全局 `model` 只覆盖空模型或历史 `deepseek::...` 默认模型；已自行设定的其他档位模型仍优先。

改错JSON时运行“检查配置.bat”，按行列提示修正；不要用局部JSON示例覆盖完整预设表。界面提供固定六档，不承诺增加任意字典键就自动得到新的完整档位。

## 桌面与可选外部客户端

桌面直接调用brain.py，不需要Cherry Studio或MCP才能让面板生效。外部MCP客户端属于进阶接法，需要另外配置本地stdio进程；服务当前提供10个工具，包括 `aipet_mood`。工具的可用性不代表所有外部客户端都会自动调用它们。

Live2D已经集成。要使用 `assets/character.png` 静态图，需要在config中关闭live2d并重启。开启鼠标穿透后可通过托盘恢复点击。

## 暂缓修订的旧信道材料

以下旧材料涉及QQ/外部信道，本轮按范围保留，不能作为当前桌面首次安装的必要步骤。QQ部分后续单独核对。

### MCP 需要信道吗？

**不需要。这是两件事，解决的问题不同。**

| | MCP server | 信道（IM 通道） |
|---|---|---|
| 解决什么 | 它思考时**读**面板和记忆 | 它主动**找你** |
| 方向 | agent ← AIPet | AIPet → 你 |
| 需要什么 | 本地 stdio，不联网 | QQ/微信/Telegram 等平台凭据 |
| 用在哪 | 你说话，它回答 | 它没事找事、定时提醒 |

两个可以独立使用：

- 只挂 MCP → 它记得住你、受面板控制，但**不会主动开口**
- 只接信道 → 它能主动找你，但**说话不带记忆和人格**（除非同时挂 MCP）
- 两个都上 → 完整形态

**所以想让面板生效，只需要 MCP，不需要信道。**
信道是为了「AI 室友」那个主动性设计才需要的。
