# 记忆系统

小日和的记忆不是「把聊天记录全塞进 prompt」。那样跑一周就会崩：prompt 无限膨胀、同一个事实被记二十遍、模型在噪音里找不到重点。

她用的是下面这套。

## 一、事实与事件分开

|  | `persona/PROFILE.md` | `memory/journal.jsonl` |
|---|---|---|
| 内容 | 当前状态快照 | 历史时间线 |
| 写入 | 覆盖 / 合并去重 | 只追加 |
| 上限 | 有，会去重 | 无，靠压缩控制 |

「用户在准备考研」是**事实**，进 PROFILE；「9 月 14 日用户说下周三要交报告」是**事件**，进 journal。两者的生命周期完全不同，混在一起必然膨胀。

## 二、每条记忆带三个元数据

- `importance` 1–5 —— 生日和「今天吃了什么」不该一个待遇
- `emotion` 情绪标签 —— 影响她回话的语气
- `decay` 遗忘速度 —— `permanent` / `slow` / `normal`

## 三、按分数检索，不全量注入

```
score = 关键词匹配 × 重要度 × 时间衰减 × 标签加成
```

时间衰减用 `exp(-λ·天数)`：

| 类别 | λ | 半衰期 | 用于 |
|---|---|---|---|
| `permanent` | 0 | 永不 | 生日、核心事实 |
| `slow` | 0.004 | ~173 天 | 长期目标、稳定偏好 |
| `normal` | 0.02 | ~35 天 | 日常事件 |

中文用单字和相邻二字做特征。两千条以内，这比 embedding 更快更省，也不用装依赖；上万条再考虑向量检索。

## 四、Token 预算硬约束

记忆注入有上限，默认 1200 tokens，按分数截断。另外有近期兜底：最近 4 条无论分数高低都注入，保证短期连贯。

## 五、分层压缩

```
30 天内    → 原样保留
30 天以上  → 压成周摘要，原始条目进 memory/archive/
180 天以上 → 再压成月摘要
```

**老记忆是降采样，不是删除。** 原始数据永远在 `memory/archive/` 里，随时能翻。

## 六、隐私过滤

`data/config.json` 里 `privacy.blocked_patterns` 命中的句子，整句拒绝入库。默认拦密码、密钥、token、身份证、银行卡。

## 群里别人说的话

QQ 群里的发言和主人自己的记忆**分开存、分开算**：

| 说话人 | 检索权重 | 重要度上限 | 衰减 |
|---|---|---|---|
| 主人 | 1.0 | 5 | 按 `decay` 字段 |
| 认得的群友 | 0.6 | 3 | 半衰期约 11.5 天 |
| 陌生人 | 0.45 | 2 | 半衰期约 4.6 天 |

群友的记忆注入 prompt 时会带「群里有人说的」前缀，避免模型张冠李戴。**把别人的事记成主人的，不是权重高低的问题，是错的。**

参数都在 `data/config.json` 的 `speaker` 段。

## 睡前整理

机制层由 Python 做：存、检索、评分、衰减、压缩、归档。语义层由 LLM 做：理解、抽取事实、合并去重、判断什么重要。

Python 做不了「这句话说明了用户什么偏好」这种判断，LLM 做不了「三年后这条记忆该不该还在」这种机械计算。所以拆开：

```bash
python src/consolidate.py brief     # Python 准备好素材
# 让 agent 读完素材，改写 persona/PROFILE.md
python src/consolidate.py done      # 打时间戳，标记本轮整理完成
```

挂成定时任务就能每天睡前跑一次。合并优先于新增 —— PROFILE 膨胀的唯一原因就是只加不减。

## 记忆面板

```bash
python src/memory.py demo       # 灌演示数据看效果（正式用之前删掉 journal.jsonl 重来）
python src/render.py --open     # 生成面板并打开浏览器
```

`view/memory.html` 是自包含的：CSS/JS 全内联，不联网，不加载 CDN。

面板上每项左边那个竖直色条是**记忆热度**，也就是时间衰减后的残余强度。永久类永远是满的，日常记忆会慢慢变暗。低于阈值就不再进对话上下文，但**不会被删除**，你还能在面板上看到它。

## 手动读写

```bash
python src/memory.py add "用户说下周三要交报告" -i 5 -t 工作,承诺 -e 压力
python src/memory.py search "报告"
python src/memory.py context "报告"        # 看这次对话会注入什么，附带 token 数
python src/memory.py stats
python src/memory.py compress              # 手动触发压缩
```

参数：`-i` 重要度 1–5 · `-t` 标签逗号分隔 · `-e` 情绪 · `-d` 衰减类别（`permanent` / `slow` / `normal`）
