# 人格管理

AIPet 把公开模板和本地人格分开：`persona_defaults/` 随代码发布，首次运行时复制到 `persona/characters/`；`persona/` 属于本机私人数据，已被 Git 忽略。

## 切换和编辑

从桌宠右键菜单或对话窗口右上角菜单打开「人格管理」。左侧选择人格，右侧直接编辑 `SOUL.md`，点「保存」即可更新这个角色，不会新建副本。当前人格会显示在对话标题里，例如「古明地觉 · 安静陪伴中」。

左侧选中的是正在编辑的角色；带「当前」标记的才是实际对话使用的角色。编辑其他角色不会自动切换，想使用它时再点「设为当前」。保存已在使用的角色后，后续对话会读取更新内容。

头像可以在同一个窗口导入，程序会保存为对应人格目录中的 `avatar.png`。头像只用于本机预览，不会改变 Live2D 模型。

## 导入或更新 SOUL

1. 左侧选中要修改的角色。若要增加全新角色，先使用现有的「新建人格」，输入名称。
2. 点「导入 SOUL」，选择 UTF-8 Markdown 文件。
3. 确认框会显示目标角色名称和目录标识。选择「Yes／是」才会覆盖该角色的 SOUL；选择「No／否」或取消文件选择都不改动。导入会替换人格文本框中尚未保存的内容，请先保留需要的修改。

导入只更新所选角色的 SOUL，保留源文件的原文字节，不增加同名副本，也不自动切换当前使用的角色。角色目录、头像、边界、示例对白、情绪方案及其未保存的编辑都保留；这些资料不会随一个 SOUL 文件一起导入。若列表中已有同名角色，会显示序号；确认时再核对目录标识。

导入覆盖和文本框「保存」都会先将旧 SOUL 原样备份到该角色的 `backups/SOUL-时间-唯一标识.md`，成功保存备份后才替换文件。备份失败会停止更换；内容字节完全相同时不新增备份。导入成功时会显示备份位置。需要回退时，选中同一角色，再用「导入 SOUL」选择该备份并确认即可。

旧版根目录的 `persona/SOUL.md` 与 `BOUNDARIES.md` 会在第一次初始化时复制到「桃濑日和」，已有本地文件不会被覆盖。修改现有角色时使用人格管理中的副本，不要再只修改旧根目录文件。

## 迁移和备份

换目录时按[README的新目录迁移流程](../README.md#从旧版本更新)操作。人格内容在整个 `persona/` 目录中，包括 `characters/`、`active.json` 和头像；情绪方案绑定和各角色状态另在 `data/`，只复制persona不能保留全部状态。普通备份已经保留完整角色相对路径、当前选择、头像、对白、边界和情绪状态；默认恢复先导出供比较，操作见 [备份与恢复](备份与恢复.md)。不要把真实的私人 `persona/` 提交到公开仓库；只提交 `persona_defaults/` 中不含私人内容的模板。
