# 人格管理

AIPet 把公开模板和本地人格分开：`persona_defaults/` 随代码发布，首次运行时复制到 `persona/characters/`；`persona/` 属于本机私人数据，已被 Git 忽略。

## 切换和编辑

从桌宠右键菜单或对话窗口右上角菜单打开「人格管理」。左侧选择人格，右侧编辑 `SOUL.md`，保存后可以设为当前人格。当前人格会显示在对话标题里，例如「古明地觉 · 安静陪伴中」。

头像可以在同一个窗口导入，程序会保存为对应人格目录中的 `avatar.png`。头像只用于本机预览，不会改变 Live2D 模型。

## 导入旧人格

选择「导入 SOUL」并打开已有的 Markdown 文件。程序会按文件名创建一个本地人格副本；之后可以在编辑器中补充边界和说话方式。旧版根目录的 `persona/SOUL.md` 与 `BOUNDARIES.md` 会在第一次初始化时复制到「桃濑日和」，已有本地文件不会被覆盖。

## 迁移和备份

换目录时，把整个 `persona/` 目录一起迁移即可，其中包含 `characters/`、`active.json` 和头像。不要把真实的私人 `persona/` 提交到公开仓库；只提交 `persona_defaults/` 中不含私人内容的模板。
