## 怎样打开测试台

完成 README 的环境准备后，在项目根目录的 PowerShell 运行：

```powershell
& .\.venv\Scripts\python.exe -X utf8 -B tools/performance_lab.py
```

便携环境将解释器替换为 `.\runtime\python.exe`。测试台不需要 API key；示意画面需要 PySide6，原生预览还需要 live2d-py、OpenGL 与完整的 Hiyori 模型资源。

先试“喝茶被拖拽打断”或“旧回复迟到”，看动作结束后恢复什么、迟到事件为何被拒绝。只检查状态规则时，无界面入口仅需 Python 标准库：

```text
python tools/performance_lab.py --scenario late_reply
```

导出文件位于使用者选择的位置，默认目录为 `work/performance-traces/`。回放核对的是事件与调度结果，不能代替真实皮套的逐帧画面验收。
