## 已完成的功能

- [x] 新装生成缺失的secrets/config/thinking，提供配置API和检查配置入口；已有配置不被模板覆盖。Windows支持3.11–3.14、优先3.12，新装默认max，主指南走DeepSeek。
- [x] 更新先解压到独立目录，准备环境后选择旧目录迁移；复制暂存校验、数据库快照、目标保护及异常回退。禁用Live2D时不再被未使用的缺失模型阻止；坏库或锁库给明确提示。
- [x] 普通备份补齐角色目录、头像、当前选择、对白、情绪文案/绑定/状态；保留相对路径和独立快照名称。恢复默认导出，明确原地恢复时校验整个包、备份当前资料并支持异常回退。
- [x] 10月1日按使用流程调整为：选中角色，沿用“导入 SOUL”确认覆盖；新角色使用已有“新建人格”入口。导入保留原文字节、当前使用的角色、头像、边界与情绪。导入和文本保存均备份旧 SOUL 后原子更换，同角色并发保存会被阻止。旧人格格式转换仍只导出候选，拒绝 `--apply`。
- [x] 回忆块按最终渲染文字估算预算并限制条数，超长条目标注截取且不修改存储原文；recall绑定本轮检索快照，阶段事实/近期兜底使用剩余额度。
- [x] 图片和Word后台读取，支持取消并防止迟到结果串话题；视觉错误不会保存成材料。Word单次解析，按正文和表格中的图片引用顺序组合，同图只识别一次，使用独立临时目录并限制资源。
- [x] Word任一必需图片失败时整份拒绝；超出图文长度不截取一部分偷偷发送。取消不能撤回已发出的视觉请求或费用。
- [x] 知识库默认关闭，手动索引后可用于普通桌面/brain命令行，独立预算默认2000、最多6块；带文件来源，旧版/损坏/过期索引不继续注入旧资料。
- [x] 搜索代理实际传入DDGS客户端；各搜索后端、网页提取和检查更新共用独立客户端路由。off不继承环境代理，手填失败不改直连；自动检测验证后续候选，缓存到期后在下次联网时重试，并隐藏代理凭据。准备入口校验固定的网络依赖版本。
- [x] README、配置说明和相关docs同步实际行为；旧版本说明、首次安装阶段记录保留历史标识，新增[备份与恢复](备份与恢复.md)。
- [x] 10月1日重写[QQ 接入](QQ机器人接入提示词.md)：内置通道直接调用人格与记忆，无需 Cherry Studio 或外部 MCP；更新身份绑定、档位跟随和排查。凭据模板与错误提示同步，QQ 启停 BAT 改为 ASCII/CRLF 并识别便携解释器。
- [x] 新增[旧安装迁移](旧安装迁移.md)，说明双击与命令行的实际差异、复制范围、群档位等手动补齐项及回退边界；未改变本轮迁移清单或向真实旧安装执行迁移。
