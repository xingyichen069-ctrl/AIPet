# 小体型桌宠 · 设计纲领

本文记录已讨论的方向，用来约束后续实现；本分支只交付视觉样例。AIPet 应用尚未接入这些新皮套和行为。

## 人格与皮套独立

- SOUL 决定相处方式；皮套决定桌面外观。灵梦形象可以使用小日和的 SOUL，用户新建的人格也可以复用现有皮套。
- 切换皮套时，询问是否保留当前人格或切到推荐人格，默认保留当前人格。
- 切换外形不覆盖 SOUL，不重建角色，不丢失现有人格的资料。

## 小巧而有角色感

- 融合两个视频参考：以紧凑小全身为基础，吸收精致眼睛、发束、小手和生活道具互动。
- 小日和保留灰棕双马尾、暗红发带、蓝灰紫眼、奶油开衫、海军蓝领口和蓝领结。其余角色保留各自的发型、配色和标志性配件。
- 当前探索约 1.8–2 头身，避免把成人比例立绘直接缩小，也不采用已否决的简单几何吉祥物风格。
- 用户可调大小，正式功能要有下限和上限。当前预览暂用 120–260 像素、默认 180；最终范围仍需结合模型占地与小尺寸可读性调整。
- 道具按状态出现，漫游时能收起，不让桌子或大配件始终绑在角色身上。

## 四种动态模式

| 模式 | 目标体验 |
| --- | --- |
| 安静 | 原地陪伴，降低动作频率，保留少量眨眼和呼吸 |
| 日常 | 原地小幅转头、视线、发束与道具活动 |
| 活泼 | 更丰富的表情、摆手和短促小跳，仍控制占地 |
| 漫游 | 用户主动开启后在桌面移动，配合站、坐和行走等动作 |

默认原地活动，漫游由用户主动开启。人物气质决定推荐动作节奏，但不把某个 SOUL 锁死在某个皮套上。

## 保留熟悉的操作

对话面板和右键主列表的条目与顺序沿用既定布局，只扩充现有“外观”子菜单，将皮套、大小和动态模式集中放在那里。

## 从样例走到模型

1. 用户选择各角色的基础稿，明确需要修改的比例、眼型、轮廓和服装。
2. 修正同一角色不同姿态之间的细节差异，清理边缘，统一标准原画。
3. 拆出脸、眼睛、眉毛、嘴、前后头发、躯干、手臂、配件和道具；补齐被遮挡部分。
4. 制作 Live2D 转头、视线、眼睑、口型、身体及手臂参数，加入发束和配件物理跟随。
5. 先验证一套基础动作及一组手部活动，再接入大小范围和四种动态行为。
