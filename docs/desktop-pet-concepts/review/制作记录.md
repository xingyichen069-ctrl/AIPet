# 制作记录 · 2026-10-01

交付为七位默认角色的 14 张待选静态原画。使用 imagegen 技能的 API/CLI 参考图编辑流程；请求模型名为 `gpt-image-2`，quality 为 medium，请求尺寸 1024×1024。实际返回尺寸见 [图片清单](../image-inventory.json)，不把请求值写成实际输出值。

## 输入与处理

小日和基础稿的第一张参考是既有桃濑日和模型渲染，第二、第三张分别用于手与道具画法、紧凑全身比例。其他六位基础稿使用小日和作为画风参考，并明确指定各自身份；活动稿使用对应角色自己的基础图编辑。

本分支保留了 [14 份原提示词](../prompts/)、[角色约束](../characters.json)、[原图](../originals/) 和 [逐图视觉检查](../visual-review.json)。参考图的角色分工写在提示词内。视频参考截图未随分支分发，来源见 [样例说明](../README.md#制作与出处)。

原图按接口返回字节保存，均含透明通道。预览图只做透明留白裁切、等比缩放和排版，没有把脸、手或服饰重新画进预览。选择标记只表示用于本轮展示，最终定稿仍待用户决定。
