# 对话与右键菜单主题

版本：0.5.0

## 怎么切换

右键桌宠，选择「外观 → 主题」。对话窗右上角的「··· → 外观 → 主题」和托盘菜单也可以切换。

| 主题 | 配色与装饰 |
| --- | --- |
| 博丽灵梦 · 朱色结界 | 朱红、米白、金色；阴阳玉与御币 |
| 雾雨魔理沙 · 星屑魔法 | 黄、黑、白；金色星形徽章与星屑 |
| 古明地恋 · 无意识之庭 | 黄、绿、蓝；闭眼爱心与蓝色连线 |
| 琪露诺 · 冰晶雾湖 | 冰蓝、白；六角雪花与结冰的湖面 |
| 古明地觉 · 觉之瞳 | 深红、梅紫；红色第三只眼，思考时眨眼 |
| 芙兰朵露 · 彩翼夜宴 | 深红、金色；七色结晶翅膀，思考时轻抖 |

六套主题都有日间与夜间版本，沿用本机时间 07:00–18:00 的日间范围。更换主题只改变界面外观，不切换人物模型、人格或回复风格。

**关于「博丽灵梦 · 朱色结界」**：这套主题原本叫「东方 · 朱色结界」，风格取自博丽灵梦——朱红巫女服配米白，符札、御币和阴阳玉。改名只是把来源写明确，配色和装饰一点没动。主题键名仍是 `touhou`，你选过的设置不受影响。

**关于「琪露诺 · 冰晶雾湖」**：取自官方设定里的两个锚点——蓝色无袖连衣裙（主色）和背后**三对六棱柱状翅膀**（所以标志画的是六角雪花，不是随便挑的）。日间是雾之湖的白昼，偏白衬衫那种浅蓝；夜间是湖面结冰的深夜，主色提亮成发光的冰。

## 更新到现有便携版

1. 退出正在运行的桌宠。
2. 将更新包内 `AIPet` 文件夹中的内容复制到原有 `AIPet` 目录，覆盖同名文件；保留原目录中的其他文件。
3. 按原来的方式启动，再从右键「外观 → 主题」选择喜欢的样式。

更新包只包含本次改动的源文件、主题设置、检查文件和说明。原来的运行环境、模型、个人配置、人格和记忆继续使用。

## 偏好与自定义

选择保存在本地 `data/appearance.json`，与字号、玻璃质感共用一个偏好文件。项目默认外观在 `themes/appearance.json`，额外样式在 `themes/custom.qss`，修改后自动重载。

`theme` 的有效值是 `touhou`、`marisa`、`koishi`、`cirno`、`satori` 和 `flandre`。已有的 `day` / `night` 自定义颜色仍有优先权；如果曾手动覆盖颜色，想恢复完整预设，可以先备份偏好文件，再移除相应的自定义颜色字段。

思考图标使用 PySide6 自带的 QPainter 和 QTimer 绘制，不引入动画库。古明地觉的眼睛在完成后固定恢复睁开；芙兰朵露的彩色翅膀只在等待期间轻抖，空闲时不刷新。
