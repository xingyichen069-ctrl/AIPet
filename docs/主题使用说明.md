# 对话与右键菜单主题

版本：0.4.0-beta.1

## 怎么切换

右键桌宠，选择「外观 → 主题」。对话窗右上角的「··· → 外观 → 主题」和托盘菜单也可以切换。

| 主题 | 配色与装饰 |
| --- | --- |
| 东方 · 朱色结界 | 朱红、米白、金色；阴阳玉与御币 |
| 雾雨魔理沙 · 星屑魔法 | 黄、黑、白；金色星形徽章与星屑 |
| 古明地恋 · 无意识之庭 | 黄、绿、蓝；闭眼爱心与蓝色连线 |

三套主题都有日间与夜间版本，沿用本机时间 07:00–18:00 的日间范围。更换主题只改变界面外观，不切换人物模型、人格或回复风格。

## 更新到现有便携版

1. 退出正在运行的桌宠。
2. 将更新包内 `AIPet` 文件夹中的内容复制到原有 `AIPet` 目录，覆盖同名文件；保留原目录中的其他文件。
3. 按原来的方式启动，再从右键「外观 → 主题」选择喜欢的样式。

更新包只包含本次改动的源文件、主题设置、检查文件和说明。原来的运行环境、模型、个人配置、人格和记忆继续使用。

## 偏好与自定义

选择保存在本地 `data/appearance.json`，与字号、玻璃质感共用一个偏好文件。项目默认外观在 `themes/appearance.json`，额外样式在 `themes/custom.qss`，修改后自动重载。

`theme` 的有效值是 `touhou`、`marisa` 和 `koishi`。已有的 `day` / `night` 自定义颜色仍有优先权；如果曾手动覆盖颜色，想恢复完整预设，可以先备份偏好文件，再移除相应的自定义颜色字段。
