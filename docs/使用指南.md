# 使用指南

首次安装只需按[首页的四步说明](../README.md#开始使用)完成准备、配置和启动。

## 日常使用

| 想做什么 | 操作 |
|---|---|
| 打开对话 | 双击角色身体 |
| 改模型、接口或外观 | 右键桌宠 → 配置 |
| 换人格、修改性格或头像 | 右键桌宠 → 人格管理 |
| 调整思考强度 | 点击角色身体打开思考面板，选择日常或自动等档位 |
| 退出程序 | 在桌宠右键或托盘菜单选择退出 |

对话框中 Enter 发送，Shift+Enter 换行。人格、外观与模型分别设置，可以按自己的需要组合。

## 配置

打开 **配置 → 模型与接口**，填写服务商提供的接口根地址和 API key，点击「获取模型 ID」并从列表选择。若服务商不提供列表，填写其官方调用名，再点击「测试当前方案」核实；新增或更换的非预置模型 ID 须核实后才能保存。最后在「默认使用」中选好方案，点击「保存更改」。测试可能产生少量 API 费用。

API key 不会自动选择最新模型，模型 ID 也不是中文展示名称。更换服务商时，应同时核对地址、密钥和模型。

其他常用选项：

- **外观与桌宠**：主题、字号、通透度、模型和尺寸；模型与尺寸改动后需要重启。
- **搜索与文件**：允许读写的文件夹、搜索和可选搜索密钥。不配搜索 API 也可以使用普通搜索。
- **人格管理**：独立编辑人格和头像，完成后点击保存。

通常可以保留其余参数的默认值。需要调整预算、环境变量或高级参数时，查阅[详细配置说明](developer_开发者/配置中心.md)。

## 图片、文件和 QQ

图片识别需先在 **配置 → 模型与接口 → 读图接口** 配置支持看图的模型。聊天窗可添加图片或 Word 文档，等读取完成后发送。文件读写范围在「搜索与文件」中指定；提醒需要程序保持运行。

QQ 是可选的独立通道，需要自己的机器人凭据，接入方法见[QQ 配置说明](developer_开发者/QQ机器人接入提示词.md)。连接后可发送 `/help` 查看[指令帮助](QQ使用帮助.md)。

## 更新

1. 退出旧桌宠；如果使用 QQ 或其他独立后台组件，也先停止它们。
2. 将新版完整解压到独立新目录，保留旧目录。在新目录运行 **准备环境.bat**，暂时不填新密钥、不改配置、不启动桌宠。
3. 在新目录打开 [tools/maintenance_维护入口/迁移私人内容.bat](../tools/maintenance_维护入口/迁移私人内容.bat)，选择旧安装文件夹，核对清单后复制。
4. 再启动新版，检查人格、历史话题与一条实际回复，确认正常后重新创建快捷方式。

使用自定义模型、外部资料目录或 QQ 群档位时，还需按[完整迁移说明](developer_开发者/旧安装迁移.md)补齐相关内容。迁移不会删除旧安装；确认新版正常前保留它。

## 常见问题

| 情况 | 先做什么 |
|---|---|
| 找不到 Python 或跳转商店 | 安装官方 Python 3.12 x64，勾选 PATH，再运行准备环境 |
| 安装下载失败 | 保留错误窗口，检查网络后重新准备环境 |
| 不能回复，出现 401/403 | 在配置中核对密钥、服务商权限和账户额度 |
| 提示模型不存在 | 核对接口根地址，重新获取模型 ID |
| 看不到角色或启动闪退 | 查看 `data/cache/windows-startup.log`；需要更多信息时使用维护目录中的「启动诊断.bat」 |
| 图片不能识别 | 检查独立的读图接口是否已配置 |

仍无法解决时，查看[Windows 排查说明](developer_开发者/Windows使用说明.md)。提供报错文字即可，不要公开密钥或整份私人资料。

详细命令、测试和实现说明集中在[开发者文档](developer_开发者/README.md)。
