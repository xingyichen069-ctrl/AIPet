# 个性化设置总览

先按 [README](../README.md) 配好大脑和基础对话，再按需要调整。编辑本机文件，保留公开 `.example.json` 和 `persona_defaults` 作为参考。JSON示例仅说明字段位置，不要用片段覆盖已有整份配置。

## 常用入口

| 想改什么 | 首选位置 | 何时生效 |
|---|---|---|
| 当前角色、人格、头像 | 菜单 → 人格管理 | 下一轮对话读取 |
| 当前人格情绪文案/借用方案 | 人格管理 → 情绪文案 | 保存后后续请求读取 |
| 字号、玻璃通透度、主题 | 菜单 → 外观 | 即时 |
| 六档与自动模式、模型 | 思考面板；`data/thinking.json` | 文件重载后 |
| 大脑/视觉接口 | 配置API.bat → `data/secrets.json` | 下一次请求读取 |
| 文件沙箱 | `data/config.json` → `tools.fs_root` | 下次工具操作读取 |
| 隐私词、检索参数、搜索后端 | `data/config.json` | 退出后重启 |
| Live2D模型、开关、尺寸 | `data/config.json` → `live2d` | 配置字段需重启；同一路径的模型资源替换可用菜单重载 |

config中的 `_说明` 等是普通JSON字符串，帮助理解字段；不是允许在JSON里写 `//` 注释。不要把说明中的箭头或中文解释复制进字段值。

## 人格与情绪

首选“人格管理”界面。当前副本在 `persona/characters/<id>/`：SOUL.md是人格，BOUNDARIES.md是该角色边界，DIALOGUE.json是示例对白，MOODS.json是情绪文案。公开模板不同角色的结构可能不同，没有统一的“九个章节/三套变体”要求。

旧的 `persona/SOUL.md` 只作小日和兼容来源；已有当前角色副本时改它可能不生效。公共边界文件仍有兼容读取用途，不要为套模板删掉私人规则。公开模板更新不会自动覆盖你编辑过的副本。

小日和情绪状态沿用 `data/mood.json`，其他角色在 `data/moods/<id>.json`；借用方案记录在 `data/persona_moods.json`。文案通过界面修改，不用编辑 `src/mood.py` 的旧CATALOG。旧 `data/mood_catalog.json` 在首次初始化时可作为小日和文案来源。

每次导入SOUL都会创建独立副本，同名或大小写相近也不会覆盖已有角色；导入保留原文字节，不自动设为当前人格。详情见 [人格管理](人格管理.md) 和 [运行时调整](人格运行时调整.md)。

## 关于你的事实

`persona/PROFILE.md` 可保存长期档案。它不一定在全新安装时存在；需要时可创建UTF-8 Markdown文件，或使用界面和对话中的记忆能力。

本版本没有安装“每晚23:30自动整理”的任务。`consolidate.py brief`只准备素材，处理素材和完成标记需要人工/外部流程。普通运行桌宠不会自动完成档案维护。

日常事实仍进入记忆时间线。手动压缩、撤回和并发写入存在审查中列出的缺口，不建议把压缩当成新用户必做保养步骤。参见 [记忆系统](记忆系统.md)。

## 思考强度

新装默认max，共六档及自动模式。当前记忆预算配置为3500至120000估算tokens，约束相关回忆块而不是整次请求；超长片段有截取标记，原记录保留。参数含义和工具限制见 [思考强度配置手册](思考强度配置手册.md)。

## Live2D与文件沙箱

在config已有的live2d对象中改enabled、model等字段。改模型时复制完整资源目录，不能只复制model3.json；文件引用必须齐全。关闭enabled后才使用静态PNG。

在tools对象中改fs_root。例如JSON中Windows路径写为 `D:\\AIPet资料`，或使用 `D:/AIPet资料`；留空使用用户主目录下AIPet文件夹。这个目录里的文件可以被工具读写，建议使用专门给桌宠的资料目录。

## 搜索与知识库

搜索后端、代理在config的tools对象中设置，改后重启。Tavily需要单独注册key；免费额度以服务商为准。本版已修正搜索代理传参、端口检测与SOCKS传输：auto在缓存到期后、下次需要联网时重测，off强制搜索/网页/检查更新直连，手填地址失败不切直连；详细步骤与限制见[工具指南](工具与沙箱.md#联网搜索)。

本地知识库默认关闭。放入TXT/Markdown后需手动build，再启用knowledge.enabled并重启，才会将相关资料块加入默认桌面/普通brain命令行对话。资料独立预算默认2000估算tokens、最多6块，保留来源；变更资料后需要重建索引。相关片段会发送给已配置的大脑API。详见 [工具与沙箱](工具与沙箱.md)。

## 建议先改哪几项

先在界面选人格和合适字号，再按需要选择档位、配置一个专用文件沙箱。其他参数可以保持发行默认。更新时保留自己的这些选择，按README迁移，不直接用新模板替换私人配置。

## 四、QQ 上的人格

**和桌宠是同一份，不用管。**

QQ 是自建的网关客户端（`src/qq_bot.py` + `src/qq_bridge.py`），
回话直接走 `brain.py`，读的就是 `persona/SOUL.md` 和同一个记忆库。
改完人格保存即生效，QQ 那边跟着变，不需要重启、也不用重贴提示词。

群聊有几条硬约束是代码层限死的，改人格也绕不过去：回复压到 300 字以内、
不发 URL、不用 Markdown、思考档位强制 daily（被动回复只有 5 分钟窗口）。

接入步骤见 → [`docs/QQ机器人接入提示词.md`](QQ机器人接入提示词.md)
