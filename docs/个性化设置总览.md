## 二、人格（最重要，先改这个）

### `persona/SOUL.md` — 它是谁

**九个分区：**

| 分区 | 改什么 | 例子 |
|---|---|---|
| 一、基本设定 | 名字、形态、跟你的关系 | `个子不高，扎双马尾` |
| 二、你看得比说的话多 | 她怎么理解世界（高位视角） | `你看得见事情底下的结构` |
| 三、可爱是你挑的，不是你的上限 | ★ 外套 vs 内核 | `不是全部可爱，是一层外套` |
| 四、说话方式 | 句子长度、用不用 emoji、要不要列清单 | `可爱体现在选词上，不体现在话变多上` |
| 五、真的会说的话 | 语感锚点，带语感的例句 | `醒了？外面下雨，伞在门口。` |
| 六、石头模式 | 被冒犯时怎么变冷 | `不用说"我生气了"，只是变冷` |
| 七、软化 | 什么情况下会松口 | `判据是他的态度，不是他的音量` |
| 八、你偶尔会停在某个状态里 | 心理点（见下方 2.1） | `起雾 / 软毛 / 低电量…` |
| 九、主动性与不做的事 | 主动性边界 + 硬性禁止 | `不卖萌换东西` |

### 2.1 心理点 —— 她自己能拨的状态

SOUL.md 定的是**底色**，心理点管的是**外套**：她自己挑一个状态停
一会儿，然后自己散掉。

| | 是什么 | 改哪儿 |
|---|---|---|
| 底色 | 她本来就是这样的人 | `persona/SOUL.md` |
| 外套 | 她此刻**选择**这样说话，几小时后回来 | `data/mood.json` + `src/mood.py` |

七种可选，各自有常规时长：

| 状态 | 时长 | 什么感觉 |
|---|---|---|
| 起雾 | 3h | 站远了，适合谈深的事 |
| 软毛 | 2h | 可爱开到最满 |
| 低电量 | 1.5h | 只剩功能，不想演 |
| 手痒 | 2h | 想动手做点什么 |
| 较真 | 2h | 精度拉满，语气可以硬 |
| 偏心 | 3h | 今天只想对一个人上心 |
| 走神 | 1h | 注意力飘出去了 |

**「随系统时间恢复」是怎么实现的：** 没有定时任务，也没有后台线程。
每条状态只存一个 `until` 时间戳，每次读的时候拿当前时间比一下，
过期就当场清掉。所以关机、睡眠、重启都不影响——时间戳是绝对的，
不像倒计时那样睡一觉就错乱。桌宠关着它也照样"恢复"。

最后两成时间进入**淡出期**，注入文本会提醒她"快散了"，
所以收尾是渐的，不是啪一下换个人。

**⚠️ 没有任何钟点。** `until` 是「挑的那一刻 + 时长」，相对量。
不存在"每天三点起雾"这种事，它也不会自己重来——散掉就是散了。

**时长每次都不同。** 不指定 `hours` 时，实际时长在常规值上下 **30%**
内随机浮动（`JITTER`）。所以「软毛」可能 1.4 小时，也可能 2.4 小时。
这是故意的：固定的时长久了就像排班表，不像心情。
写死 `hours` 才不浮动。

**防滥用：** 刚散掉 2 小时内挑不了（冷却），一天最多 4 次，单次 1–8 小时。
**冷却不拦你**——你明确开口要换时她会带 `force=true` 照做。

### 2.2 你的话怎么影响她

两种，分量完全不同：

| | 触发 | 她怎么处理 |
|---|---|---|
| **建议** | 你的话里碰到某些词 | 只是**摆个选项**给她看，挑不挑在她 |
| **指令** | 你说"可爱一点""正常点""收一收" | 照做，`force=true`，冷却不适用 |

建议的对应表在 `src/mood.py` 的 `TRIGGERS`：

| 你说的话里有 | 可能让她想 |
|---|---|
| 累 / 撑不住 / 熬夜 / 失眠 / 难受 | 偏心 |
| 喜欢你 / 爱你 / 抱抱 / 谢谢你 | 软毛 |
| 闭嘴 / 好烦 / 烦人 / 没用 | 低电量 |
| 无聊 / 没事干 / 打发时间 | 手痒 |
| 为什么 / 意义 / 活着 / 值不值得 | 起雾 |
| 不对 / 错了 / 认真点 / 精确 | 较真 |
| 随便 / 都行 / 算了 / 懒得 | 走神 |

**注意「建议」不会自动切换。** 命中只是让注入的上下文里多一行
"听到「好累」→ 可以停到「偏心」：他听着状态不好"，后面还跟着
"挑不挑随你，这不是命令"。她可以完全无视。

这样做是刻意的：上一节说了心理点是**她自己挑的姿态**，
如果这里改成关键词自动触发，那句话就假了。

命中是子串匹配，会有误报（比如"积累"命中"累"）。无所谓——
反正是给她看的选项，不是自动执行。

改词表就编辑 `TRIGGERS`，改指令词就编辑 `COMMANDS`。

**改法和查看：**

```bash
python src/mood.py                    # 现在停在哪个状态
python src/mood.py list               # 有哪些可选
python src/mood.py set 软毛 2 "他今天话很多"
python src/mood.py clear              # 立刻恢复
```

想加自己的状态，编辑 `src/mood.py` 里的 `CATALOG` 字典
（`feel` / `voice` / `sample` / `avoid` / `hours` 五个字段）。

记忆面板和 `python src/memory.py show` 里都能看到当前状态。

**写法要求（文件里也写了）：写具体行为，别写抽象形容词。**
- ❌ "它很幽默" → 模型理解得含糊
- ✅ "它喜欢冷幽默，但不会连着讲两个笑话" → 有约束力

**更好的办法：多写她实际会说的话。**

模型学语气是从**例句**学的，不是从形容词学的。SOUL.md 里那节
「她真的会说的话」就是干这个的——写十句带语感的例句，
比写十条规则管用。

### ⚠️ 一个容易踩的坑：注释里别再写注释

`SOUL.md` 顶部那段用 `<!-- -->` 包起来的说明，**不会进入她的脑子**。
`brain.py` 在注入前会把 HTML 注释剥掉。

**但注释里不能再出现注释的结束标记**，否则会提前闭合，
后面的说明文字就漏进人格里了——她会读到"这是你最该动手改的文件"
这种话，然后把自己理解成一份待编辑的文档。

（这个坑我踩过一次，症状是她的回答里开始带文档腔。）

**文件里还有三个现成的性格变体**（元气型 / 老友型 / 学者型），
想换路子直接把「性格底色」「说话方式」两节替换掉。

### `persona/BOUNDARIES.md` — 不能做什么

权重**高于** SOUL，冲突时以它为准。

- 隐私红线（哪些不记录）
- 不假装（不编造记忆、不假装执行了没做的事）
- 情绪边界（遇到自伤倾向怎么办）
- 不主动联系其他人、不诱导消费

**最后一节是写给你的**，关于情感依赖的提醒，值得读一遍。

## 三、关于你的事实

### `persona/PROFILE.md`

**这个文件程序会自动维护，你也可以手改。**

分区：身份 / 作息与节律 / 在做的事 / 喜好 / 忌讳 / 重要日期 / 长期目标

**两条规则：**
1. **写事实，不写日志。** ❌"9月14日用户说他下周三要交报告"
   ✅"在准备课程设计报告（2026-09 起）"
2. **「重要日期」区永不遗忘。** 生日填这里。

**你现在该做的**：把生日填进去。这是投入产出比最高的一条。

```markdown
## 重要日期

- 3 月 15 日 生日  `2026-09-14`
```

**日常不用管它** —— 每晚 23:30 有定时任务自动整理。

## 四、QQ 上的人格

**和桌宠是同一份，不用管。**

QQ 是自建的网关客户端（`src/qq_bot.py` + `src/qq_bridge.py`），
回话直接走 `brain.py`，读的就是 `persona/SOUL.md` 和同一个记忆库。
改完人格保存即生效，QQ 那边跟着变，不需要重启、也不用重贴提示词。

群聊有几条硬约束是代码层限死的，改人格也绕不过去：回复压到 300 字以内、
不发 URL、不用 Markdown、群聊默认 daily（被动回复只有 5 分钟窗口）。群内所有成员可用 `/档位 daily`、`/档位 deep` 或 `/档位 神格` 切换当前群；神格状态会保留更长的群聊上下文，但仍受 QQ 的回复时限和消息长度限制。

接入步骤见 → [`docs/QQ机器人接入提示词.md`](QQ机器人接入提示词.md)

## 五、思考强度

  "enabled": true,

## 七、她能读写哪些文件（沙箱根）

`fs_list` / `fs_read` / `fs_write` / `fs_mkdir` 四个工具**只能动沙箱根里面**的东西。
这是代码层拦的，不是靠她自觉。

默认根是**用户主目录下的 `AIPet` 文件夹**（Windows：`%USERPROFILE%\AIPet`）。
想改成别处，编辑 `data/config.json`：

```json
{
  "tools": {
    "fs_root": "D:\\我的资料"
  }
}
```

留空 = 用默认值。改完保存即生效，不用重启。

**这一项值得认真设。** 设成哪里，她就能读、能写、能建目录到哪里：

| 想让她干嘛 | 根设成 |
|---|---|
| 只帮我收 QQ 上发来的东西 | 默认值就够 |
| 帮我整理某个资料盘 | 那个盘的某个子目录，别设成整盘根 |
| 什么都别碰 | 建个空文件夹，指过去 |

设窄一点更安全。设在文档/资料目录上更方便，但那也意味着她在那个目录里
能改任何文件 —— 写坏了要靠你自己有备份。

**拦得住什么**（路径先解析成真实路径再验归属，所以这些都会被拒）：

```
../../../secrets.json                 → 被拒
读取/../../../AIPet/data/secrets.json  → 被拒（合法根 + 用 .. 钻出去）
//?/C:/Windows                        → 被拒（设备路径）
D:/其他目录/x.txt                      → 被拒（带盘符且不在沙箱内）
```

带盘符的绝对路径不在沙箱里时会**明确拒绝**，而不是剥成相对路径。
单次读写上限 20 万字节。

**看图不受这个限制** —— `see_image` 能看电脑上任何位置的图片（拖进来的
文件本来就在各处）。它靠另外两道闸门把关：后缀白名单 + 文件头魔数。
详见 → [`工具与沙箱.md`](工具与沙箱.md)

## 八、记忆系统调参

### `data/config.json` → `retrieval` / `scoring` / `compression`

| 症状 | 调什么 |
|---|---|
| 老忘记你几周前说的事 | 调大 `retrieval.token_budget` |
| 回复里塞了一堆不相关的旧事 | 调大 `retrieval.min_score` |
| 换话题了还揪着老的 | 调小 `retrieval.recency_floor` |
| 忘得太快 | 调小 `scoring.decay_lambda.normal` |
| 压缩太早/太晚 | 调 `compression.daily_to_weekly_after_days` |

**`privacy.blocked_patterns`** —— 加你自己的隐私词，命中的整句不记录。

## 九、网络搜索

### `data/config.json` → `tools`

```json
{
  "proxy": "auto",           ← 自动检测代理，不用管
  "search_backend": "ddgs",  ← ddgs / tavily / searxng
  "cache_ttl": { "general": 3600, "news": 900, "page": 86400 }
}
```

**代理是自动的**：启动桌宠时后台探测一次，读 Windows 系统代理 +
扫常见端口 + 实际验证能不能出境外。右键角色可以「重新检测代理」。

出问题时：`python src/proxy.py`

## 十二、如果只改三样

1. **`SOUL.md` 里的一句话长度** —— 嫌它话少就调大，嫌啰嗦就调小，立刻有感
2. **`PROFILE.md` 的生日** —— 一次投入，永久受益
3. **`SOUL.md` 四、脾气** 里的忌讳 —— 什么别碰、什么时候别找它说话

剩下的交给它自己。你正常聊天，每晚 23:30 的定时任务会把对话内化进档案。
