# AIPet · QQ 指令手册

> 把命令留在手边，把聊天留给对话。
>
> **群聊：先实际 @机器人，再发送命令。** 私聊可以直接发送。

## 一眼找到你要的操作

| 想做什么 | 发送什么 | 谁能用 |
| :--- | :--- | :--- |
| 打开这份手册 | `/help` | 所有人 |
| 看符卡推送状态 | `/符卡` | 主人 |
| 预览一张符卡 | `/符卡 预览` | 主人 |
| 开启或关闭本群推送 | `/符卡 开启` · `/符卡 关闭` | 主人 |
| 查看可用定时任务 | `/定时任务 列表` | 主人 |
| 查看或调整思考强度 | `/档位` · `/档位 日常` | 主人 |
| 查询 Tavily 用量 | `/tavily` | 主人 |
| 查看版本及是否有更新 | `/版本` | 主人 |

**“主人”是 AIPet 已绑定的身份，不等同于 QQ 群主或管理员。** 菜单可供所有人查看，执行时仍检查身份。认领口令不在本手册中展示。

## 符卡 · 每天三次的小惊喜

在目标群中发送：

```text
/符卡 状态
/符卡 预览
/符卡 开启
/符卡 关闭
```

每天 **北京时间 10:00、14:00、22:00** 各发一张，附持有者；128 张符卡轮换，采用固定开头“叮！今日份符卡推送：”，卡名竖排显示。

- 每个群独立开关，默认关闭；不开启就不推送。
- `预览` 不开启任务，也不推进正式推送的位置。
- QQ 的群权限、禁言和主动消息额度会影响投递；错过的时段不补发。

## 定时任务 · 留给以后的扩展入口

```text
/定时任务 列表
/定时任务 状态 spellcards
/定时任务 预览 spellcards
/定时任务 开启 spellcards
/定时任务 关闭 spellcards
```

`spellcards` 是现有符卡任务的名称。以后增加任务模板，仍可用这组命令管理。所有修改只作用于发送命令的当前群。

## 思考档位 · 按问题选择投入

| 档位 | 适合怎样的使用 |
| :--- | :--- |
| 自动 | 由问题决定投入 |
| 省电 | 简单短聊，减少消耗 |
| 日常 | 普通聊天与问答 |
| 认真 | 需要较完整解释 |
| 深究 | 多步骤分析 |
| 极限 | 复杂问题，投入更高 |
| 雷霆（需配置） | 扩展高投入档位，需先在运行端配置对应预设 |

```text
/档位
/档位 日常
/档位 跟随
```

不带参数会显示当前档位。群里调整只影响本群；`跟随` 清除本群覆盖，恢复跟随**当前运行端**的默认设置。切换群档位不会修改其他群或桌面的默认选择。

可用选项以 `/档位` 的实际回复为准；没有配置的档位会提示缺少预设，不会显示切换成功。

## 联网与版本 · 查询不会偷偷执行别的操作

**`/tavily`** 查看已用次数和剩余额度，不执行搜索，也不消耗搜索次数。普通境内检索先走常规网络，确实需要境外来源时才按需使用 Tavily；普通搜索失败不会自动改走 Tavily。

**`/版本`** 查看当前版本并检查更新，**不会下载或安装**。也可使用 `/更新`、`/检查更新`。

## 保存 Markdown 文档

在**桌面聊天**或**主人与机器人的 QQ 私聊**里，可以这样说：

> 把刚才的内容整理成 Markdown，保存到「笔记/讨论整理.md」，包含标题、要点和表格。

机器人已有受限文件工具，可以新建、覆盖或追加 UTF-8 的 `.md` 文件。生成新的正文通常需要模型；保存已经给定的文字由文件工具完成。

- 文件只写入该运行端配置的文件工作区。
- 群聊没有通用文件读写权限，不能借此查看或修改主人的私人文件。
- 生成的文档保存在运行程序的文件工作区；保存成功不代表已经发到 QQ，主人可从该工作区取回。

## 小提示

- 点击原生候选菜单只会填入文字，发送后才执行；参数用空格分隔。
- `/help`（也可写 `/帮助`）发送这份现成文档，不调用模型或搜索。
- 已处理指令及其回复不进入后续模型聊天上下文；指令附带的图片和文件不自动读取。
- 普通群消息只作有限背景；需要回复时请实际 @机器人。
- 若 QQ 客户端不能预览 `.md`，下载后用支持 Markdown 的阅读器打开，即可查看标题和表格排版。
