## 开发检查

从项目根目录运行，使用本项目解释器；便携环境可替换为 `runtime\python.exe`：

```bat
.venv\Scripts\python.exe tools\test_core.py
.venv\Scripts\python.exe tools\test_core.py test_onboarding test_settings_ui
```

隔离入口只复制公开代码与模板，使用合成资料并拦截常规 Python socket 连接。不要在自己的运行资料上直接执行整套旧 selftest；部分旧工具会联网或修改资料。原生 GUI、真实接口与长期常驻需要分别验证。

源码在 `src/`，辅助脚本在 `tools/`，自动化检查在 `tests/`。此次文档和入口整理不改变这些模块的物理位置；`data`、`persona`、`memory` 等私人资料继续留在原安装。

## macOS（实验性）

固定依赖要求 macOS 15+、CPython 3.11–3.14，建议用 uv 选择 3.12；尚无 Mac 实机验收。

完整解压后双击根目录的 `启动桌宠.command`。若无执行权限，在项目终端运行 `chmod +x 启动桌宠.command`。首次生成的 `data/secrets.json` 可用纯文本编辑器配置；更新到新目录时先准备和迁移，再正式启动：

```sh
zsh 启动桌宠.command prepare
.venv/bin/python tools/update_wizard.py
```
