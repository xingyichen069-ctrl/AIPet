# 维护入口

这里用于排查、迁移或管理可选 QQ 通道。普通使用只需要根目录的 **准备环境.bat → 配置API.bat → 启动桌宠.bat**。

| 脚本 | 作用 |
|---|---|
| 查看状态.bat | 查看桌宠与 QQ 状态；可追加 `--watch 2`、`--log 40` |
| 检查配置.bat | 只检查本地配置格式，不验证账户或发起模型请求 |
| 启动诊断.bat | 在控制台启动桌宠，显示诊断输出 |
| 停止桌宠.bat | 界面无法操作时，从外部停止本安装的桌宠 |
| 查看记忆.bat | 显示本安装的记忆 |
| 迁移私人内容.bat | 打开迁移向导，也可将旧安装文件夹拖到此脚本上 |
| 启动QQ.bat / 停止QQ.bat | 启停本安装的独立 QQ 通道 |

所有脚本仍以所属项目根目录为工作目录，运行环境、资料位置和底层 Python 工具保持不变。可以从资源管理器打开，也可以在其他工作目录调用；有空格的路径和参数需要加引号。

这些脚本已从根目录迁到这里。更新后的快捷方式若指向旧脚本位置，应重新创建；已有旧安装的入口不受影响。

完整命令见[命令行参考](../../docs/developer_开发者/命令行参考.md)，迁移前阅读[更新步骤](../../docs/使用指南.md#更新)。QQ 关闭独立于桌宠退出；迁移前按指南停止旧安装的相关进程。
