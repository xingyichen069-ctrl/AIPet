# AIPet

一个住在桌面上的角色，提供 Live2D、对话历史、人格管理、提醒和本地记忆。

当前版本 `0.5.0-beta.2` ｜ [更新日志](CHANGELOG.md) ｜ [本轮修订与验证记录](docs/0.5.0-beta.2修订记录.md)

界面和资料文件保存在本机。对话会发送给你配置的 API；看图另需视觉接口。下面先走默认 DeepSeek 的配置路径。

## 第一次使用：Windows

适用于 Windows 10/11 **x64**。准备程序支持 Python **3.11–3.14 x64**，优先选择3.12；也可使用 uv。原生 ARM64 Python 和32位 Python 不在本轮支持范围内。

### 1. 下载并解压 main

从 [main 下载源码 ZIP](https://github.com/xingyichen069-ctrl/AIPet/archive/refs/heads/main.zip)，右键解压到你有写入权限的目录，例如 `D:\AIPet`。打开后应能看到 `README.md`、`src` 和 `准备环境.bat`。

不要直接在压缩包预览里运行，也不要解压到 `Program Files` 等需要管理员权限的目录。GitHub 源码包不包含 Python 环境、任何人的密钥、私人记忆或人格副本。

### 2. 准备环境

- 还没有 Python/uv：安装 [Python 3.12 的 Windows 64位安装程序](https://www.python.org/downloads/windows/)，勾选 **Add python.exe to PATH**。已经有3.11–3.14 x64或uv可跳过。
- 双击 **准备环境.bat**，等窗口显示环境和配置检查结果。首次需要联网下载依赖，下载量通常为数百MB。
- 如果失败，请保留错误窗口，按 [Windows排查说明](Windows使用说明.md) 处理。重新运行不会覆盖已填写的配置。

准备成功后会创建三份本机文件：

| 文件 | 用途 |
|---|---|
| `data/secrets.json` | API密钥和接口地址；文件名是 **secrets**，带末尾的s |
| `data/config.json` | 外观之外的程序配置、文件沙箱、隐私词等 |
| `data/thinking.json` | 当前档位、模型、各档参数；新装默认 **max（极限）** |

对应的 `*.example.json` 是公开模板。平时只编辑没有 `.example` 的本机文件。准备阶段不生成人格，便于更新用户先迁移旧资料。

### 3. 填写 API

双击 **配置API.bat**，会用记事本打开 `data/secrets.json`。默认接 DeepSeek 时，在 `deepseek_api_key` 后面的英文双引号内填入你自己的 key，其余先保持不变，例如：

```json
{
  "deepseek_api_key": "在这里填写你自己的key",
  "deepseek_base_url": "https://api.deepseek.com",
  "model": "",
  "vision_api_key": "",
  "vision_base_url": "",
  "vision_model": ""
}
```

这是一份结构示例，示例文字不能直接当key。实际文件中带 `_` 的说明字段可以保留。**已有其他配置时只改对应值，不要用示例覆盖整份文件。**

按 Ctrl+S 保存。使用英文双引号、英文逗号；最后一项后面不加逗号，不添加 `//` 注释。密钥不要写入 `.example.json`，也不要截图或发出填好的文件。

双击 **检查配置.bat**。它检查文件格式、必要字段和填写状态，不发送API请求、不显示密钥内容。格式通过不代表密钥、账户额度或模型权限已经可用。

### 4. 启动并确认

双击 **启动桌宠.bat**，在对话框发一句“你好”。正常收到回复后，基础对话配置才算完成。

- 默认是 **max**，不会因为一句短消息自动降档。想用日常或自动模式，可从右键菜单打开思考面板切换；当前选择会保留。
- 右键角色或对话框的 `···` → **人格管理**，选择或编辑人格。新装首次正式启动时才生成本机人格库。
- 重新启动一次，确认刚才的话题仍在。可以设一个“一分钟后提醒我休息”的约定；提醒需要程序保持运行。
- 没有回复时看对话框错误，再查 [Windows排查说明](Windows使用说明.md)。无需反复重填整份配置。

## 从旧版本更新

**将新版解压到新的、独立的文件夹；旧目录保留供回退。** 本仓库还有其他开发分支，main用户请使用上面的main下载链接。程序原有“检查更新”暂时会比较全仓标签，不能据此确定标签属于main。

完整的复制清单、手动补齐项和失败处理见 **[旧安装迁移指南](docs/旧安装迁移.md)**。

1. 从旧桌宠菜单退出，另行停止旧QQ及自行启用的后台组件；关闭桌宠窗口不等于QQ已经停止。
2. 将main ZIP解压到例如 `D:\AIPet-new`，不要覆盖旧目录，也不要把新目录放到旧目录里面。
3. 在**新目录**双击 **准备环境.bat**。此时不要填写新key、编辑配置或启动桌宠；准备生成的空模板可以迁移。
4. 双击 **迁移私人内容.bat**，选**旧目录**（包含 `src`、`data` 的那一层），核对来源、目标、文件数量和类别后确认。入口不会结束进程；新目录已有私人资料或已编辑配置时会拒绝覆盖，应另用干净新目录。
5. 按指南补齐需要的自定义资源和QQ群档位，再启动新版，确认**当前人格、历史话题、约定、档位/模型，以及一条实际回复**。QQ需单独从新目录启动和核对。
6. 成功后从新目录重新创建桌面快捷方式，检查开机启动项。旧目录继续留着；回退时先退出新版桌宠和QQ，再打开旧版。新版产生的新资料不会自动合并回旧版。

迁移会复制密钥、配置、人格库/头像/当前选择、记忆、对话与约定数据库、情绪绑定及各角色状态。原有档位和模型会保留，不自动套用新版参数或改写私人SOUL。QQ绑定、最近会话、媒体和token缓存会复制；**群单独档位 `data/qq_group_levels.json` 需手动补齐或重设**。

运行环境、自定义主题和全局立绘/模型、自定义知识库目录、外部沙箱、目录型及子目录历史备份不会自动补齐。启用中的自定义模型缺失，或旧配置的 `paths` 与新版默认布局不同时，入口会停止并提示；完整模型文件夹需先按配置位置复制。已关闭Live2D的缺失模型只提醒，日后启用前仍需补齐。

复制前会暂存校验并备份新目录中将被覆盖的文件，写入失败会尝试回退；“已复制，但配置还需检查”则表示资料已经复制，需要修正新配置。迁移备份不是旧安装的完整备份，也可能含密钥。普通ZIP备份同样不能代替旧目录留存，详见 [备份与恢复](docs/备份与恢复.md)。

`migrate_persona_runtime.py` 只导出可选的人格格式候选和差异，旧 `--apply` 已停用；它不是普通更新步骤。参见 [人格运行时说明](docs/人格运行时调整.md)。

## 可选配置

### 人格与外观

在界面里使用“人格管理”和“外观”即可。修改现有角色时，直接编辑文本框并保存，或选中角色后用“导入 SOUL”，确认后覆盖并备份旧文件；新角色先点“新建人格”。当前人格文件位于 `persona/characters/<id>/`，公开默认模板不会覆盖已有私人副本；修改旧的 `persona/SOUL.md` 未必影响当前角色。详见 [人格管理](docs/人格管理.md) 与 [个性化设置总览](docs/个性化设置总览.md)。

### 看图

在现有 `secrets.json` 中填写 `vision_api_key`、`vision_base_url`、`vision_model`；不使用就留空。需要支持 `image_url` 消息的视觉模型。填写服务商给出的接口根地址和模型名，保留已有大脑字段。图片和Word附件会在后台读取，可取消；读取成功后才能发送。Word中的任一图片读不了，整份材料都会拒绝添加，请修正或拆分后重试。详见 [工具与沙箱](docs/工具与沙箱.md)。

### 文件读写

默认范围是用户主目录下的 `AIPet` 文件夹。若要改，编辑 `config.json` 中已有的 `tools.fs_root` 值，例如 `D:\\AIPet资料`，不要用单行片段替换整份文件。daily档不开放文件读写工具，需要切到提供相应工具的档位。

### 本地知识库（可选）

默认关闭。将TXT/Markdown资料放入项目的 `knowledge` 文件夹，手动建立索引，再开启 `config.json` 的 `knowledge.enabled` 并重启。默认桌面对话和普通命令行会选取相关片段，带文件来源发给你配置的大脑API；放入文件不等于已经生效。资料变动后需要重建索引。完整步骤见 [工具与沙箱](docs/工具与沙箱.md#本地知识库)。

### 其他大脑服务

当前主配置路径以DeepSeek为准。虽可填写兼容 `/chat/completions` 的其他地址，现有请求仍带DeepSeek专用参数，严格的第三方服务可能拒绝；本轮没有完成通用供应商适配。

接口根地址不要重复包含 `/chat/completions`。可选 `model` 填服务商提供的模型名：仅在档位仍使用 `deepseek::...` 或未指定模型时覆盖它；已自定义的档位模型优先。模型前缀不是自动切换供应商。环境变量 `DEEPSEEK_*`、`OPENAI_*` 可优先于文件，检查配置会提示是否存在这类变量而不显示值。

### 配置何时生效

人格、档位和外观有各自的重载机制。`config.json` 的搜索后端、隐私词、检索参数等仍需**退出后重启**；不能笼统认为保存即可全部生效。`tools.fs_root` 会在使用时读取。

联网搜索默认自动检测代理。开关代理软件后可右键桌宠 → 高级 → 重新检测代理；如需手填地址或关闭代理，见[搜索配置与排查](docs/工具与沙箱.md#联网搜索)。搜索、网页读取和检查更新共用此设置，检测通过不保证所有搜索服务都可用。

**能直接接 QQ，无需 Cherry Studio 或外部 MCP。** 在 `data/secrets.json` 填写 QQ 开放平台机器人的 `qq_appid`、`qq_secret`，用“启动QQ.bat”启动独立通道。它直接调用当前人格和记忆，群聊与私聊默认跟随桌面档位；群覆盖可用 `/档位 跟随` 清除。配置、身份绑定、当前发送处理和排查步骤见 [QQ 接入](docs/QQ机器人接入提示词.md)。接入指南已更新，其他 QQ 权限与实机会话问题仍需后续审查。

## macOS：实验性

固定依赖要求 **macOS 15+、CPython 3.11–3.14**，建议uv选择3.12。尚无Mac实机验收，不保证较旧macOS可安装。先解压，再双击 `启动桌宠.command`；系统首次可能需要通过右键“打开”确认。若提示无执行权限，可在终端进入解压目录后执行 `chmod +x 启动桌宠.command` 再打开。

首次生成的 `data/secrets.json` 仍需按上文填写。若尚无key，界面可以启动，但不能获得模型回复。Mac使用默认文本编辑器直接编辑该JSON文件，保持纯文本格式。

Mac更新也使用独立新目录。先退出旧程序，在**新目录**的终端依次运行以下两条命令；第一条只准备，不启动桌宠，也不提前生成人格：

```sh
zsh 启动桌宠.command prepare
.venv/bin/python tools/update_wizard.py
```

复制完成后再双击启动。此路径未做Mac实机验证。

## 验证与当前范围

项目仍为beta。使用已有解释器和公开资料副本完成了Windows离线功能验证与独立Live2D渲染；完整在线安装下载、实际DeepSeek账号回复、Mac和长期常驻仍需实机验收。确切结果及审查编号见 [beta.2修订记录](docs/0.5.0-beta.2修订记录.md)；前一阶段见 [首次安装记录](docs/首次安装与指南修订记录.md)。

开发者可在项目目录运行隔离测试（便携安装把解释器换成 `runtime\python.exe`）：

```bat
.venv\Scripts\python.exe tools\test_core.py
```

测试只复制公开模板并拦截常规Python socket连接，不使用你的私人配置。其他脚本的自检可能改数据或联网，勿把它们当作第一次使用的必做步骤。
